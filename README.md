# 🔐 Password Strength Checker

A beginner-friendly Python project that checks the strength of a password.

## ✨ Features

- Checks password length
- Checks for numbers
- Checks for uppercase letters
- Checks for lowercase letters
- Checks for special characters
- Gives a score out of 5
- Rates the password as Weak, Medium, or Strong

## 🛠️ Built With

- Python

## ▶️ How to Run

Run the `password_checker.py` file and enter a password when prompted.

```text
Enter your password: Farin123!
